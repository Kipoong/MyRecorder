## 사용 방법

1. 모니터를 고르고 **선택 모니터 전체** 또는 **영역 드래그 선택**을 누릅니다.
   선택 직후 초록 테두리와 물리 픽셀 크기가 표시됩니다. 다른 모니터로 옮기려면 그 모니터를
   선택한 뒤 전체/영역 버튼으로 다시 지정하세요. 직접 드래그는 현재 모니터 안으로 제한됩니다.
2. 대기 중 테두리의 이름표 또는 조절점이 아닌 선 부분을 드래그하면 이동합니다.
   모서리·각 변 중앙의 8개 조절점으로 크기를 바꿉니다. 최소 크기는 32 논리 픽셀입니다.
   전체 화면은 이동 여유가 없으므로 먼저 조절점으로 줄인 뒤 이동하세요.
3. 녹화 시작 시 빨간색으로 바뀌며 조절점이 사라집니다. 테두리는 입력 통과 모드가 되어
   녹화 중 강의 창 조작을 막지 않도록 합니다. 실제 Windows 입력 통과는 재검증이 필요합니다.
4. 일시정지 시 주황색을 유지하고 재개하면 빨간색이 됩니다. 녹화 세션 안에서는 위치·크기를
   바꾸지 않습니다. 모든 구간의 해상도/위치를 유지하여 기존 FFmpeg 결합과 오디오 동작을 보호합니다.
5. MP4 저장을 마치면 초록색으로 돌아오며 다시 이동·크기 조절할 수 있습니다.
6. **녹화 영역 테두리 표시**를 해제하면 숨기고 다시 체크하면 표시합니다.
   녹화·일시정지 중에도 사용 가능하며 시작/종료 등 작업 처리 중에는 잠시 비활성화됩니다.
   숨겨도 실제 녹화 영역과 오디오 설정은 바뀌지 않습니다. 다음 앱 실행은 기본 표시 상태입니다.
7. 영역 선택 오버레이 또는 OCR 화면 캡처 중에는 잠시 숨겼다가 복귀합니다.

레이블의 `가로×세로 px`는 선택 영역의 **물리 픽셀**입니다. 크기를 확인할 수 없으면
`DIP`로 표시하고 녹화 시작의 기존 DPI 검사를 유지합니다. 인코더는 홀수 크기를 짝수로
패딩하므로 파일 폭/높이가 선택값보다 각 1픽셀 커질 수 있습니다.

## 영상 제외 처리와 한계

- 새 `window_capture.py`는 현재 프로세스의 최상위 오버레이 창임을 확인한 뒤
  `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`와 읽기 확인을 사용합니다.
- 다른 프로그램 창의 속성은 변경하지 않습니다. 강의 보호 기술을 우회하는 기능이 아닙니다.
- 일반 영역은 테두리와 이름표를 가능한 한 캡처 밖에 배치합니다. 화면 끝/전체 화면은
  안쪽 표시가 필요하므로 Windows 제외 속성의 실제 동작 확인이 특히 중요합니다.
- 속성 설정 또는 읽기 확인이 실패하면 녹화 시작 전에 숨깁니다. 녹화/재개, 창 핸들 변경,
  표시 체크박스 재설정에도 확인합니다. 저장 버튼 직후 프로세스가 아직 살아 있는 동안도 같은 규칙입니다.
- 제외 실패는 녹화 엔진을 바꾸거나 중단하지 않습니다. 메인 화면에 자동 숨김 이유를 표시합니다.
  프로세스가 멈춘 대기/일시정지에서는 테두리를 다시 보여줄 수 있습니다.
- **API가 성공해도 실제 gdigrab 영상에서 제외됨을 테스트한 것은 아닙니다.**
  DWM·Windows 빌드·그래픽/원격 데스크톱 환경에 따라 검증해야 합니다.
  영상에서 테두리/이름표·검은 상자·빈 영역이 보이면 체크를 해제하고 녹화 결과와 로그를 확인하세요.

[Microsoft SetWindowDisplayAffinity 문서](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)는
WDA_EXCLUDEFROMCAPTURE가 Windows 10 2004부터 지원되고 특정 Windows 캡처 경로에 적용됨을 설명합니다.
이 속성의 확인만으로 모든 캡처 방식/환경에서 제외를 보장하지 않습니다.

로그는 기존 세션의 `recording-events.jsonl`에 `overlay_capture_policy`, `overlay_resume_policy`,
`overlay_state`로 남습니다. 표시 요청·실제 표시 상태·제외 적용/이유·물리 영역을 확인할 수 있습니다.
로그는 로컬 Temp 안에만 저장하고 공개 저장소에는 포함하지 않습니다.

## 회귀 방지 범위

V0.4 대비 `recorder.py`, `audio.py`, `media.py`, `display.py`, `settings.py`, 제목/OCR 구현,
requirements와 install/run/build 스크립트는 변경하지 않았습니다.
변경은 GUI와 독립 오버레이/영역 편집/자체 창 제외 모듈, 버전 표식·문서·테스트입니다.
개인 settings.json 스키마와 Recordings/Converted/Temp 기본 경로도 동일합니다.
녹화 중 영역 편집을 막으며 체크박스는 캡처 인자·FPS·샘플레이트·녹화 파일을 바꾸지 않습니다.

## 개발 환경에서 실행한 검사

- Linux unittest 88개 통과: 기존 73개 유지, 편집 경계/최소 크기/8개 핸들/음수 원점,
  자체 창 확인·API 거부·이전 값·읽기 실패 검사 추가.
- 기존 Qt GUI smoke 통과: 저장 경로·제목/OCR·실패 복구 등 회귀 검사.
- 새 Qt overlay smoke 통과: 상태 전환, 실제 Qt 렌더링 색상, 모의 마우스 이벤트와 신호 연결,
  녹화/일시정지 편집 잠금, 표시 토글, 픽셀 라벨, 전체 화면, OCR 일시 숨김,
  제외 거부/핸들 변경/저장 시작 중 자동 숨김 확인.
- **Qt offscreen은 네이티브 마스크·마우스 캡처·창 올리기를 지원하지 않는다는 경고가 있었습니다.**
  계산한 마스크와 이벤트 로직은 검사했지만 Windows의 실제 마우스 입력 통과를 검증한 것이 아닙니다.
  Windows API도 가상 응답으로 검사했으며 실제 영상 제외 성공으로 보고하지 않습니다.

```sh
python -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen PYTHONPATH=. python tests/gui_smoke.py
QT_QPA_PLATFORM=offscreen PYTHONPATH=. python tests/overlay_smoke.py
```
