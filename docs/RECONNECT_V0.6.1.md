# V0.6.1 — 최초 한 번 페어링, 이후 자동 재연결

이번 업데이트에서는 **인증 정보와 연결 포트를 기억**합니다.
앱/브라우저를 껐다 켤 때마다 토큰을 복사할 필요가 없습니다.
자동 재연결은 통신 복원만 뜻합니다. 대상 강의 선택과 자동 감지 ON은 복원하지 않으며
재연결만으로 화면·오디오 녹화가 시작되지 않습니다.

## 업데이트 후 처음 한 번

1. MyRecorder를 종료하고 기존 폴더와 개인 설정을 백업합니다.
2. GitHub Code → Download ZIP 내부 파일을 기존 개발 폴더에 덮어씁니다.
   `settings.json`, `preferences.json`, `.venv`, `bin`, F드라이브 파일은 유지합니다.
3. 기존 설치 환경이 정상이라면 **run.bat만 실행**해 V0.6.1을 확인합니다. 추가 Python 패키지는 없습니다.
   처음 설치하거나 `.venv`가 없는 경우에만 install.bat을 먼저 실행합니다.
   EXE 사용자는 `build.bat`으로 다시 빌드합니다. Windows EXE 빌드는 미검증입니다.
4. Chrome/Edge 확장 관리 화면에서 기존 MyRecorder 확장의 새로고침을 누릅니다.
   기존과 같은 `browser_extension` 폴더를 유지하세요. 강의 페이지도 새로고침합니다.
5. 앱에 확장 ID를 넣고 **로컬 연결 시작** → 표시된 연결 정보를 확장 팝업에 붙여넣기 →
   **현재 강의 탭 연결**을 누릅니다. 이번 업그레이드 이후 한 번만 하는 새 페어링입니다.
   앱과 확장을 함께 업데이트해야 새 서명 통신을 사용할 수 있습니다.

## 이후 평소 사용

- PC/앱 재시작 후 **run.bat만 실행**합니다. install.bat을 매번 실행할 필요가 없습니다.
- 앱이 저장한 연결을 자동 복원합니다. 허용했던 사이트의 확장은 저장한 정보로 다시 연결합니다.
- 확장 팝업에 토큰을 다시 넣거나 **로컬 연결 시작**을 매번 누르지 않습니다.
- 녹화하려면 앱에서 강의 video를 확인하고 **강의 재생 자동 감지**를 켭니다.
- 처음 방문하는 새 강의 사이트는 확장 팝업에서 **현재 강의 탭 연결**을 한 번 눌러 사이트 권한을 허용합니다.
  연결 정보 입력란은 비워 둬도 저장한 인증 정보를 사용합니다.
- 브라우저나 강의 탭이 열려 있지 않으면 앱은 대기합니다. 앱이 브라우저를 임의 실행하지 않습니다.

## 저장 방식과 보안 범위

### Windows 앱

`%LOCALAPPDATA%\MyRecorder\browser-pairing.dpapi`에 확장 ID·포트·인증키를 저장합니다.
Windows **현재 사용자 DPAPI**로 암호화하며 평문 파일 대체 저장은 하지 않습니다.
개발/OneDrive 폴더나 녹화 폴더에 인증 파일을 넣지 않습니다.
다른 Windows 사용자/PC로 암호화 파일만 복사해서 재사용하는 방식은 지원하지 않습니다.

### Chrome/Edge 확장

암호문은 해당 확장의 `chrome.storage.local`에, 내보낼 수 없는 AES-GCM 키는
해당 확장 Origin의 IndexedDB에 저장합니다. 토큰을 평문 local storage나 sync storage에 저장하지 않습니다.
사용자가 허용한 사이트 목록도 기억하고, 브라우저 시작 시 스크립트 등록/기존 허용 탭 연결을 복원합니다.

**브라우저 IndexedDB의 키가 Windows DPAPI로 암호화된다고 주장하지 않습니다.**
브라우저 프로필 보안에 의존하며 같은 사용자 계정/프로필이 장악된 상황을 방어하는 제품은 아닙니다.
다른 브라우저 프로필, 확장 삭제/ID 변경, 사이트 권한 회수, 프로필 초기화 후에는 다시 연결이 필요할 수 있습니다.

### 로컬 통신

127.0.0.1만 사용하고 저장한 포트로 복원합니다. Windows의 저장 연결은 HMAC 요청·응답 서명을 요구합니다.
재연결 요청마다 원문 인증키를 전송하지 않습니다. 요청 본문·임의 nonce·시간을 서명하고
응답 서명도 확인하여 다른 서비스의 가짜 ready를 신뢰하지 않습니다.
기존 Host/Origin/확장 ID/본문 크기/이벤트 순서 검증을 유지합니다.
타임스탬프는 30초 창, nonce는 실행 중 제한된 재사용 방지 캐시로 검사합니다.
앱 재시작 시 인증은 유지되어도 선택 대상/armed/이전 준비 응답은 모두 초기화합니다.

## 연결 삭제·재페어링

1. 현재 녹화를 저장해 대기 상태로 만듭니다.
2. 앱의 **연결 초기화**를 누르고 확인합니다. Windows 암호화 파일을 삭제하고 서버를 닫습니다.
   이후 새로 연결하면 다른 인증키를 만듭니다.
3. 확장 팝업의 **저장한 연결 삭제**도 누릅니다. 암호문·키·허용 사이트 자동 등록 정보를 삭제합니다.
   페이지에 남은 래퍼를 없애려면 강의 페이지도 새로고침합니다.
4. 필요하면 최초 페어링 절차를 다시 진행합니다.

한쪽만 삭제하면 반대쪽에 이전 연결 정보가 남습니다. 자동으로 다른 키를 신뢰하거나 평문으로 복구하지 않습니다.
암호화 파일이나 브라우저 프로필을 공개 저장소/로그/문제 보고에 첨부하지 마세요.

## 자동 복원 실패 시

- 저장 포트가 다른 프로그램에 사용 중이면 연결 복원 실패를 표시합니다. 임의의 다른 포트로 바꾸지 않습니다.
  다른 MyRecorder 인스턴스를 닫거나, 대기 상태에서 연결 초기화 후 새로 페어링하세요.
- Windows 계정/프로필 변경, DPAPI 복호화 오류, 파일 손상 시 기존 파일을 보존하고 재페어링을 안내합니다.
- 브라우저 키/암호문 복원 실패 시 자동으로 새 인증 정보를 만들지 않습니다. 확장에서 삭제 후 새로 연결합니다.
- 확장 업데이트/브라우저 정책으로 사이트 권한이 사라졌다면 해당 사이트를 다시 허용해야 합니다.
- 복원 실패는 수동 화면·오디오 녹화를 차단하지 않습니다. 기존 강의 자동 연동의 지원 범위와 누락 가능성은
  [V0.6 안내](AUTO_LINK_V0.6.md)를 그대로 따릅니다. 순환 프리롤이나 0ms 동기화가 추가된 버전은 아닙니다.

## 검증

- Linux 자동 테스트 **153개**: 기존 검사에 암호화 저장/실패/초기화, 동일 포트·키 복원,
  충돌 차단, 서명·응답 검증·재전송/변조/이전 키 거부 검사를 추가했습니다.
  DPAPI 저장 테스트는 가짜 암호화 객체로 로직을 검증했으며 실제 Windows DPAPI 통과 판정은 아닙니다.
- Qt 모의 저장 복원 후 Recorder 생성 없음, 자동 감지 OFF, 인증 정보 숨김, 명시적 초기화를 확인했습니다.
- 실제 Linux Chromium에서 암호문 저장/내보내기 불가 키, 앱 서버 재시작, **브라우저 프로필 재시작**,
  저장한 사이트 감지 복원, 토큰 재입력 없는 재연결과 연결 삭제를 확인했습니다.
- 기존 자동 강의 연동 및 화면/오디오/MP4 회귀 검사는 유지합니다. 실제 Windows 드라이버 시험은 아닙니다.

### Windows 재검증 — 미검증

1. 최초 페어링 후 앱을 종료/재실행합니다. 토큰 입력 없이 연결되고 녹화는 대기 상태인지 확인합니다.
2. Chrome와 Edge 각각 종료/재실행하고 기존 허용 사이트를 열어 자동 연결되는지 확인합니다.
3. PC 재부팅 후 run.bat만 실행하여 같은 동작을 확인합니다.
4. 새로운 사이트에서는 토큰 입력 없이 사이트 권한만 허용하면 연결되는지 확인합니다.
5. 자동 감지 ON 후 기존 5회 정지/재개, MP4 하나, 실제 영상·음성 싱크와 F드라이브 저장을 재검증합니다.
6. 연결 초기화 후 이전 연결이 거부되는지, 새 페어링으로 복원되는지 확인합니다.
7. 다른 Windows 계정/복호화 실패/포트 충돌에서 잘못된 연결 대신 안내하며 수동 녹화가 유지되는지 확인합니다.
8. DPAPI 파일과 확장 암호문에 평문 토큰이 없고 로그/공개 소스에 인증 정보가 포함되지 않는지 확인합니다.
