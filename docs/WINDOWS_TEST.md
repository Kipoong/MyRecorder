# Windows 11 수동 검증표 — 전 항목 미실시

테스트 날짜, Windows 빌드, Python/FFmpeg 버전, CPU/GPU, 출력/입력 장치,
모니터 배율·해상도, FPS·화질을 먼저 기록하세요. 원본 임시 폴더도 보관하세요.

1. **첫 실행**: install.bat, run.bat. FFmpeg 미설치 시 안내가 나오는지 확인.
2. **무음 영상 30초**: 오디오 둘 다 해제, 전체 화면 녹화. 커서 on/off, 15/30 FPS 확인.
3. **영역 30초**: 단일 모니터 사각 영역 선택. 저장 영상 좌표/크기가 맞는지 확인.
   영역 재선택, 음수 좌표 보조 모니터, 테두리 포함 여부도 확인.
4. **시스템 소리**: 오디오 체크 후 테스트 음원 재생. 시스템 소리만 출력되는지 청취.
   무음 장치에서 빈 데이터 오류가 발생하는지도 기록.
5. **마이크 및 동시 녹음**: 손뼉/말소리와 화면 시계를 함께 녹화.
   두 소리 모두 있는지, 클리핑·작은 소리·에코가 있는지 확인. 헤드폰 권장.
6. **일시정지**: 10초 녹화 → 10초 일시정지 → 10초 재개.
   약 20초 파일인지 확인. 경계 음성 누락·중복, 최소 5회 반복 후 싱크 확인.
7. **파일**: 한글·공백·작은따옴표 경로, 동일 제목 2회, CON 같은 제목,
   폴더 기억, 열기 확인. 네트워크 드라이브는 별도 테스트.
8. **30분 이상**: 시작/중간/끝의 시각과 손뼉으로 영상·오디오 오차를 측정.
   목표 기준은 시작·끝 절대 오차 각 200ms 이내, 시작 대비 오차 변화 100ms 이내.
   현재 이 목표를 달성했다는 근거는 없음. RAM/CPU·드롭·용량 기록.
9. **1~3시간**: 30분 테스트 통과 후 같은 방식으로 반복. 절전/화면 잠금 비활성은
   사용자 판단으로 설정. 앱은 자동으로 시스템 설정을 바꾸지 않음.
10. **오류**: 쓰기 권한 없는 폴더, 여유 공간 부족(별도 테스트 볼륨 권장),
    기본 장치 분리, FFmpeg 중단. 오류 안내 및 원본 임시 파일 보존 확인.
11. **복구**: 복구 전 세션 복사. 30초 녹화 중 프로세스 강제 종료 후 CLI 복구.
    마지막 구간 일부 손실은 가능. 복구 MP4 재생과 오디오 직접 확인.
12. **EXE**: build.bat 후 dist 전체 폴더로 실행. Python 없는 별도 Windows PC에서도 확인.

## Linux에서 실제 실행한 검증

`python -m compileall -q myrecorder launcher.py`
`python -m unittest discover -s tests -v`

초기 버전 4개 테스트 통과: Windows 파일명 정리, 동일 제목 덮어쓰기 방지,
자체 생성 WAV 헤더 복구, 합성 영상+시스템/마이크 모사 오디오 2개 구간 결합 및
2배속→1배속 변환(원본 보존·길이·A/V 스트림 길이 차이·디코딩 검사).

합성 테스트는 실제 Windows 화면·WASAPI 장치·사람이 듣는 음질/싱크·장시간
안정성·BAT·EXE·GUI를 검증하지 않습니다. OCR과 제목 자동 인식은 미구현입니다.

추가 Linux Qt 검사: PySide6 6.12.0 offscreen 환경에서 창·영역 선택 위젯 생성,
초기 버튼 활성 상태, 영역 정보 표시, 작업 스레드 결과 전달과 버튼 복구 확인.
실제 디스플레이 조작이나 Windows 캡처 검증은 아님. Fontconfig 캐시 및 offscreen
raise() 경고가 있었으나 검사는 통과함. Python 3.12 x64용 PyAudioWPatch 0.2.12.7
Windows wheel 다운로드와 사용 API 이름 확인. DLL 로딩·장치 접근은 미검증.

## 0.2 저장 경로 추가 Windows 테스트 — 미실시

- ZIP을 README의 정확한 allthetest 경로에 풀고 install/run/build BAT 실행.
- F드라이브가 있는 PC에서 최초 실행: 세 폴더 자동 생성, 개발 폴더 settings.json 생성 확인.
- F드라이브가 없는 별도 환경: 경고·설정 화면, 취소 후 녹화 차단, 자동 C 저장 없음 확인.
  실제 드라이브를 무리하게 제거하지 말고 테스트 PC/VM에서 실시.
- 녹화·변환·임시를 각자 한글·공백 경로로 변경, 앱 재실행 후 설정 유지 확인.
- OneDrive 및 개발 폴더 내부 선택 시 거부 확인.
- 녹화 후 Recordings에는 최종 MP4, Temp/session-*에 원본 구간과 로그가 있는지 확인.
- 실험용 변환 결과가 Converted로 가고 중간 처리가 Temp를 사용하는지 확인.
- 다른 드라이브 조합에서 MP4 게시, 대상 쓰기 실패, 원본 보존 확인.
- EXE를 dist 아래에서 직접 실행해 개발 루트 settings.json을 재사용하는지 확인.

0.2 Linux 검증: unittest 12개 통과. Windows 경로 정책과 드라이브 누락은 모사 검사이며
실제 드라이브 접근 성공을 의미하지 않음. 파일시스템 간 최종 게시도 EXDEV 오류 모사 검사.
실제 합성 미디어는 분리된 임시/녹화/변환 경로에서 결합·변환·디코딩을 확인.
Qt offscreen에서 세 폴더 생성, 설정 저장/재읽기, 경로 읽기 전용 표시, 접근 불가 설정의
경고·설정 안내 및 녹화 시작 차단을 확인. Fontconfig 캐시 경고가 있으나 검사는 통과.
