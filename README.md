# MyRecorder V0.4.2 — Windows 11 개인용 화면 녹화

**V0.3 Windows 11 기본 기능 테스트 통과 — 사용자 실기 보고:**
화면 녹화, WASAPI 시스템 오디오 녹음, F드라이브 MP4 생성·저장 모두 정상.
이 기록은 V0.3의 기본 기능에 대한 것이며 V0.4의 새 기능 통과를 의미하지 않습니다.
V0.4 Windows 창 제목/OCR·DPI·일시정지 싱크·EXE는 추가 실기 확인이 필요합니다.

## V0.4.2 듀얼 모니터 대응 수정

Qt/Windows 화면 목록 순서 대신 장치 식별자·가상 데스크톱 원점·DPR·물리 해상도로 검증합니다.
음수 원점과 모니터별 배율을 처리하고, 선택 후 변경된 화면은 녹화 시작 전에 차단합니다.
**화면 좌표 진단** 버튼과 Temp의 `display-diagnostics-*.jsonl`에서 실패 조건을 확인할 수 있습니다.
DPI 초기화는 Qt GUI 생성 전에 한 번 수행하고 이미 설정된 모드를 보존합니다.
한 화면 내부 부분 영역/전체 화면이 대상이며 두 화면을 가로지르는 녹화는 지원하지 않습니다.

**Linux 자동 테스트 105개와 Qt smoke 통과. 실제 Windows 듀얼 모니터·DPI·캡처는 미검증입니다.**
기존 오디오·녹화 엔진·저장 설정 파일은 변경하지 않았습니다.
[원인 분석·좌표 규칙·안전한 업데이트·Windows 재검증 절차](docs/DISPLAY_V0.4.2.md)

## V0.4.1 영역 테두리 보완

선택 직후부터 **대기 초록 / 녹화 빨강 / 일시정지 주황** 테두리를 표시합니다.
대기 중 이름표·테두리를 드래그해 이동하고 8개 조절점으로 크기를 바꿀 수 있습니다.
**녹화 영역 테두리 표시** 체크박스로 숨기거나 다시 표시하며, 물리 픽셀 크기도 표시합니다.
녹화·일시정지 중 영역은 고정하여 기존 구간 결합·오디오 동작을 유지합니다.

자체 오버레이에 Windows 영상 제외 속성을 적용·확인하고, 설정 실패 시 실제 캡처 중에는
자동 숨깁니다. **실제 Windows gdigrab 영상에서 제외되는지는 아직 검증하지 않았습니다.**

## V0.4 변경 내용

- **제목 자동 인식**: 직전 활성 강의 창 또는 목록에서 고른 창의 제목을 가져옵니다.
- **영역 OCR**: 제목 영역을 드래그한 뒤 수동으로 인식합니다. Tesseract는 선택 설치입니다.
  인식 결과는 강의 제목에 표시되고 직접 수정할 수 있습니다. 녹화 중에는 인식하지 않습니다.
- 제목 금지문자 정리, 실패 시 기존 제목/기본 이름 유지, 중복 MP4 번호 추가를 유지합니다.
- Qt와 Windows 물리 모니터 좌표를 대응하여 100/125/150% 배율의 좌표를 변환합니다.
  이전의 중복 DPI 설정을 제거했습니다. **Windows에서 새 DPI 동작은 미검증입니다.**
- 일시정지 후 구간 길이, 저장 후 최종 영상 길이로 시간을 보정하고 A/V 길이를 검사합니다.
- 녹화 실패 로그를 추가하고, 최종 MP4가 확인된 정상 완료 세션만 사용자의 확인 후 정리합니다.
- V0.3 WASAPI 구현과 FFmpeg 캡처·인코딩 설정은 유지합니다. 배속 변환 GUI는 다음 버전입니다.

## 다운로드 및 기존 폴더에 업데이트

1. https://github.com/Kipoong/MyRecorder 의 **Code → Download ZIP**으로 내려받습니다.
2. 앱을 종료하고 기존 개발 폴더와 개인 `settings.json`을 백업합니다.
3. ZIP의 `MyRecorder-main` 안에 있는 파일/폴더를 기존 `myrecorder` 개발 폴더에 덮어씁니다.
   `myrecorder\myrecorder\gui.py`와 `myrecorder\run.bat`의 기존 위치를 유지하세요.
   기존 `.venv`, `bin`, `settings.json` 및 F드라이브 파일을 삭제하거나 새 폴더로 대체하지 마세요.
4. `install.bat` → `run.bat` 순서로 실행하고 제목 표시줄의 **V0.4.2**를 확인합니다.
   Python 의존성은 동일하며 가상환경을 지우거나 Python을 재설치할 필요는 없습니다.
5. 먼저 V0.3에서 성공한 동일 영역·시스템 소리로 30초 녹화하여 회귀 여부를 확인합니다.

실제 `settings.json`은 ZIP/Git에 포함하지 않습니다. 예시만 `settings.example.json`에 있습니다.
이 버전은 기존 설정 스키마를 바꾸지 않으므로 저장 경로를 유지합니다.

## 처음 설치

- Python 공식 사이트 https://www.python.org/downloads/windows/ 에서 **Python 3.12 x64**와
  Python Launcher(`py`)를 설치합니다.
- FFmpeg 공식 안내 https://ffmpeg.org/download.html#build-windows 에서 Windows 빌드를 선택하고
  `ffmpeg.exe`, `ffprobe.exe`를 프로젝트 `bin` 폴더에 넣습니다. gdigrab/libx264/AAC 지원이 필요합니다.
- ZIP의 최상위 폴더 이름을 `myrecorder`로 변경해 아래 개발 위치로 옮깁니다.
- `install.bat`은 프로젝트 `.venv`에 PySide6/PyAudioWPatch를 설치합니다. 인터넷이 필요합니다.
- `run.bat`을 실행합니다. 필요한 미디어 폴더를 생성하고 쓰기 가능 여부를 확인합니다.

| 용도 | 기본 경로 |
|---|---|
| 개발·실행·설정 | `%USERPROFILE%\OneDrive\바탕 화면\allthetest\myrecorder` |
| 녹화 MP4 | `F:\MyRecorder\Recordings` |
| 변환 MP4 | `F:\MyRecorder\Converted` |
| 구간·음성·중간 파일·로그 | `F:\MyRecorder\Temp` |

**저장 경로 설정**에서 세 경로를 바꿀 수 있고 종료 후에도 유지됩니다.
F드라이브가 없거나 쓸 수 없으면 경고하며 다른 위치를 직접 고르게 합니다.
C드라이브로 자동 대체하지 않고, OneDrive·개발 폴더 안의 미디어 저장도 거부합니다.
설정·소스·가상환경·빌드 산출물은 개발 폴더에 있지만 영상·임시 녹화는 그곳에 만들지 않습니다.

## 창 제목 인식

1. 브라우저에서 해당 강의 탭을 활성화한 뒤 녹화 앱으로 돌아옵니다.
2. 인식 방식 **창 제목**, 대상 **직전 활성 창**을 선택하고 **제목 자동 인식**을 누릅니다.
   활성 창을 기억하지 못한 경우 **강의 창 목록 새로고침** 후 해당 창을 직접 선택하세요.
3. 강의 제목 입력창의 결과를 확인하고 수정한 뒤 녹화를 시작합니다.

창 제목에는 사이트·브라우저 이름이 포함될 수 있으며 사용자가 수정할 수 있습니다.
숨은 브라우저 탭, DOM, 계정 정보는 읽지 않습니다. 인식 실패 시 현재 제목은 유지됩니다.
입력창까지 비어 있으면 기본 `강의_날짜_시간`을 사용합니다.

## OCR 제목 인식 (선택 설치·수동 실행)

녹화와 창 제목 인식에는 OCR 설치가 필요하지 않습니다.

1. [Tesseract 공식 설치 안내](https://tesseract-ocr.github.io/tessdoc/Installation.html)의 Windows 항목에서
   안내하는 배포처를 이용해 Tesseract 5 x64와 **kor/eng 언어 데이터**를 설치합니다.
   Windows 설치 프로그램은 해당 문서가 소개하는 별도 배포처에서 제공합니다.
2. 필요하면 **OCR 엔진 선택**에서 `tesseract.exe`를 지정합니다. PATH 또는 일반 설치 위치도 검색합니다.
   EXE 하나만 복사하면 DLL/언어 데이터가 빠질 수 있으므로 전체 설치를 권장합니다.
3. 제목이 보이는 모니터를 고르고 **OCR 제목 영역 선택**으로 제목 부분만 드래그합니다.
4. 방식 **영역 OCR**, 언어 **한국어+영어**를 선택하고 **제목 자동 인식**을 누릅니다.
5. 결과를 검토하고 수정합니다. 영역 이동·화면 배율 변경 후에는 영역을 다시 선택하세요.

OCR 순간 앱 창을 잠시 숨겨 이미지를 메모리로 읽고 다시 표시합니다. 이미지와 OCR 텍스트를
별도 임시 파일에 저장하지 않습니다. 인식 결과로 저장하는 제목·파일명은 세션에 남습니다.
낮은 대비·작은 글자·복잡한 배경·가려진 제목은 오인식될 수 있습니다. kor 데이터가 없으면
설치 안내가 표시되며 기존 제목을 유지합니다. OCR 실행 제한 시간은 30초입니다.

## 녹화와 저장

모니터 전체 또는 드래그 영역을 선택하고 FPS/화질/커서, 시스템 출력 장치와 마이크를 고릅니다.
실제 소리가 나오는 Windows 출력과 GUI 장치 선택을 일치시키세요.
녹화 → 일시정지 → 재개 → 종료/MP4 저장 순으로 조작합니다.
현재 단축키는 앱에 포커스가 있을 때만 동작합니다: 시작 Ctrl+Shift+R,
일시정지/재개 Ctrl+Shift+P, 종료 Ctrl+Shift+S.

녹화 중 시계는 경과 시간의 추정값입니다. 일시정지 시 닫힌 구간의 실제 길이로 보정하고,
저장 완료 후 최종 영상 스트림의 재생 시간을 초 단위로 내림해 표시합니다.
스트림 길이 검사는 실제 입 모양 싱크나 음질 검사를 대신하지 않습니다.

같은 제목의 MP4가 있으면 `(1)`, `(2)`를 붙여 기존 영상을 보존합니다.
원본 MKV/WAV는 Temp의 `session-임의ID`에 보관합니다. 저장 실패 시 세션과 로그를 지우지 않습니다.
다른 드라이브로 저장하는 경우 최종 게시를 위해 대상 폴더에 잠시 `.partial` 파일을 쓸 수 있습니다.
PCM 오디오는 채널 수에 따라 큰 공간을 사용하므로 충분한 여유 공간이 필요합니다.

## 임시 세션 정리·복구·로그

- **완료 세션 임시 파일 정리**는 정상 종료된 모든 구간과 최종 MP4의 존재·크기·스트림을 확인합니다.
  후보와 용량을 보여주고 사용자가 삭제를 확인한 뒤 다시 검사합니다. 최종 MP4는 삭제하지 않습니다.
- 실패 구간이 있거나, 저장 실패·출력 분실·손상·알 수 없는 이전 버전 세션은 보존합니다.
  심볼릭 링크/정션을 포함한 세션도 자동 정리하지 않습니다.
- V0.4 녹화 이벤트/저장 실패 로그: `Temp\session-ID\recording-events.jsonl`
- V0.3 오디오 진단 로그와 독립 시험 명령은 [오디오 안내](docs/WINDOWS_AUDIO_V0.3.md)에 있습니다.
- 복구는 원본을 먼저 복사한 뒤 프로그램이 종료된 상태에서 복사본에 실행하세요.

```bat
.venv\Scripts\python.exe -m myrecorder.cli recover "F:\MyRecorder\Temp\session-ID" --output "F:\MyRecorder\Recordings"
```

완전한 정전·디스크 손상 복구를 보장하지 않습니다. WAV 헤더 복구는 자체 PCM 형식과 4GB 미만에 제한됩니다.

## EXE와 남은 작업

FFmpeg 준비 후 `build.bat`으로 PyInstaller를 설치·빌드합니다.
`dist\MyRecorder\MyRecorder.exe`를 폴더 전체와 함께 사용하세요. V0.4는 `windows.manifest`로
모니터별 DPI를 선언하므로 이 파일도 프로젝트에 두어야 합니다. 기존 EXE는 다시 빌드해야 갱신됩니다.
**Windows V0.4 EXE 빌드/실행은 미검증이며 ZIP은 소스코드입니다.**

DRM·HDCP 우회는 구현하지 않습니다. 보호된 화면은 검게 녹화될 수 있습니다.
전역 단축키·배속 변환 GUI는 아직 없습니다. 영역 직접 조절은 V0.4.1의 대기 상태에서 제공합니다.
배속 변환 실험용 CLI는 유지하며 다음 버전에서 GUI에 통합할 예정입니다.
